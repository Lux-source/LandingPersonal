Things I made
Custom ERP

An ERP that lives on the clinic's PC

Handles room-based scheduling, clients, sales, stock and the cash register of an aesthetic clinic, and sends automatic appointment reminders through WhatsApp.

Architecture on AWS and Azure Source

How it works

on-premise, no external server
  1. Front desk Scheduling by room and staff, client records and daily cash.
  3. Next.js standalone App and API in a single Node server, with Prisma over one SQLite file.
  5. Worker A node-cron process that schedules the reminders.
  7. WhatsApp Cloud API Appointment reminders to clients.

Why I built it

A small clinic does not need a monthly SaaS subscription or a server to maintain. It needs something that runs on the front-desk computer, works without internet and whose data fits on a USB stick.

What it taught me

  • Deploying on-premise forces you to think about what the cloud gives you for free: a Windows service, backups and schema upgrades without data loss.
  • SQLite is a very serious database when there is a single writer.
